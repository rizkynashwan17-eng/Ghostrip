Yang sering ditanyakan

Apakah aplikasi ini aman?

Ya. File APK dibuat dan dibagikan langsung oleh tim Ghostrip lewat halaman ini. Peringatan dari Android muncul karena aplikasi belum dipasang lewat Play Store, bukan karena ada masalah.

HP apa saja yang bisa dipakai?

Semua HP Android versi 5.1 ke atas. Untuk iPhone belum tersedia.

Kalau ganti HP, data saya hilang?

Tidak. Pengaturan kop surat, TTD, data truk, dan riwayat tersimpan di akun. Install Ghostrip di HP baru lalu masuk dengan akun yang sama.

Apakah harus selalu pakai internet?

Internet dibutuhkan saat pertama masuk dan untuk menyimpan data ke akun. Setelah itu menghitung dan membuat penawaran tetap bisa saat sinyal lemah; data terkirim sendiri saat internet tersambung.

Muncul tulisan "Aplikasi tidak terinstal"?

Biasanya karena masih ada Ghostrip versi lama dengan tanda tangan berbeda. Hapus Ghostrip lama dulu, lalu install lagi. Data Anda aman karena tersimpan di akun.

Lupa password atau belum punya akun?

Hubungi admin Ghostrip lewat WhatsApp. Akun dibuat oleh admin, dan Anda bisa mencoba gratis selama 7 hari.

Siap kirim penawaran lebih cepat?

Download Ghostrip sekarang. Kalau butuh akun atau bantuan, admin kami siap membantu.
